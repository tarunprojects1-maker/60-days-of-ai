# Day 16 – Claude Custom Skills

## Objective

Learned how to create reusable AI Skills in Claude and use them for stock fundamental research.

## Activities Performed

* Created a new Claude Custom Skill
* Set the skill name as `stock-fundamental-research`
* Added the provided description and instructions
* Saved and configured the skill
* Tested the skill using Infosys Ltd (INFY)
* Generated a detailed stock research report
* Reviewed valuation, growth, financial health, ownership trends, and peer comparisons
* Explored reusable AI workflows through Custom Skills

## Key Learnings

* Learned how Claude Skills can automate repetitive prompting tasks
* Understood the importance of reusable AI workflows
* Learned basic stock fundamental analysis concepts
* Explored financial metrics such as P/E, ROE, ROCE, and Free Cash Flow
* Understood how AI can generate structured research reports and visualizations
* Improved understanding of AI-assisted financial research

## Outcome

Successfully created and tested a reusable stock-fundamental-research skill and generated a comprehensive stock analysis report for Infosys Ltd.
