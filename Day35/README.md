# Day 35 – Prompt Puzzle

## Objective

The objective of today's experiment was to understand the importance of prompt engineering by solving interactive prompt-based challenges. The simulator focused on improving prompt-writing skills, identifying effective prompt structures, and understanding how well-crafted prompts produce more accurate and useful AI responses.

---

## What I Did

In this experiment, I generated the Prompt Puzzle application as an HTML project and tested it in my browser. After answering the onboarding questions by selecting the domain and difficulty level, I explored the interactive prompt engineering challenges.

I completed all three prompt challenges, where I analyzed prompts, identified areas for improvement, and selected the most effective prompt structure for different scenarios. After finishing the challenges, I reviewed the Prompt Performance Report, which evaluated my overall performance, prompt quality, accuracy, and provided recommendations for improvement.

To compare different outcomes, I replayed the simulator using another domain and difficulty level. Finally, I captured screenshots of the important stages and documented the complete learning experience.
