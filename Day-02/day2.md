# Day 2 - Prompt Engineering

## Topic

Prompt Engineering

## What I Worked On

Today, I learned the importance of Prompt Engineering and how the quality of prompts directly affects the quality of AI-generated responses.

I compared a basic prompt with a structured engineered prompt and observed the differences in response quality, organization, and depth.

## Lazy Prompt

Explain Machine Learning.

## Engineered Prompt

Act as an experienced AI and Machine Learning professor teaching a second-year B.Tech student.

Explain Machine Learning from beginner to intermediate level.

Include:

* Definition of Machine Learning
* Importance of Machine Learning
* Types of Machine Learning
* Real-world Applications
* Advantages and Disadvantages
* Examples
* Common Algorithms
* Career Opportunities
* Summary Table
* Quiz

Use clear headings, bullet points, and student-friendly explanations.

## Key Learnings

* Well-structured prompts generate better responses.
* Adding context improves accuracy.
* Assigning a role helps AI provide expert-level explanations.
* Detailed prompts reduce ambiguity.
* Prompt Engineering is an essential AI skill.

## Observations

The lazy prompt produced a short and generic response, while the engineered prompt generated a more detailed, structured, and informative explanation with examples and better organization.

## Conclusion

Prompt Engineering helps users get more accurate, useful, and professional outputs from AI tools.
