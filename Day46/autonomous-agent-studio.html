How The Agents Work responsibility of each role, and how the stop-check governs the flow
Planner
Reads the brief once and produces a structural outline: thesis, section beats, and the angle the Executor should write toward. Runs once, at the start.
Executor
Writes the actual draft. On round 1 it writes from the Planner's outline; every later call it never runs again as "Executor" — its job is handed to Improver, which rewrites in place using accumulated feedback.
Safety Monitor
Screens every draft — the first one and every revision — for brand-safety, factual over-claiming, or policy issues before it's allowed to reach the Evaluator.
Evaluator
Scores the current draft 0–10 against the quality rubric (clarity, structure, engagement, depth) and returns a numeric score plus reasoning. Runs fresh every round — no cached scores.
Critic
Gives qualitative, line-level critique independent of the numeric score — what's weak, what's strong, what a human editor would flag.
Memory Manager
Distills what's been tried across rounds into durable "lessons learned" so the Improver doesn't repeat a fix that already failed or re-introduce a cut weakness.
Improver
Rewrites the draft using the current draft + this round's Evaluator score + Critic notes + Memory Manager lessons. Its output becomes next round's draft.
Final Reviewer
Runs once, after a stop condition fires. Takes the last accepted draft and does a final polish pass — no structural changes — for publication.
Each round, in strict order: (1) Plateau — has the score improved by less than 0.3 for two consecutive rounds? (2) Threshold — has the score crossed 8.5 / 10? (3) Hard cap — has round count hit 12? (safety fallback only — not the intended ending).
The stop-check is what routes information forward: while none fire, Evaluator → Critic → Memory Manager output feeds the next Improver call and the loop returns to Safety Monitor → Evaluator. The instant one fires, the loop breaks and hands off to Final Reviewer instead of looping again.
