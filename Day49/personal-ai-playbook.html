What this tool does

This is your personal library of reusable AI prompt systems. Workflows are saved, editable prompt templates for tasks you repeat often. The Prompt Builder lets you assemble a one-off prompt from labeled building blocks (role, objective, constraints, etc.) with a live preview. The Loop Builder turns any prompt into a self-checking, repeating instruction set with defined stop conditions. Everything is saved privately in this browser — nothing leaves your device.

How the Prompt Builder works

Click blocks on the left to add them to your prompt on the right, in any order. Each block is one labeled part of a well-structured prompt (like "Role" or "Constraints"). Fill in the small fields inside each block, and watch the full prompt assemble itself live at the bottom. When it looks right, copy it or save it as a reusable workflow.

How the Loop Builder works

A "loop prompt" asks the AI to work on something, judge its own output against criteria you set, and keep improving it until a stop condition is met — instead of stopping after one pass. Paste any normal prompt below, then define the goal, how quality is judged, how it should improve each round, when to stop, and any safety limits. This produces a ready-to-use autonomous prompt.

What is this?

Personal AI Playbook is a private, offline library of AI prompt systems you can reuse and adapt, instead of writing prompts from scratch every time.

⌂ Dashboard — overview of your stats, profile, and recently used workflows.
▤ Workflows — your full library of saved, editable prompt templates, organized by category.
✎ Prompt Builder — assemble a single custom prompt from labeled building blocks with a live preview.
↻ Loop Builder — turn any prompt into a self-checking, repeating instruction set with a defined stop point.
★ Favorites — quick access to the workflows you star.
⚙ Settings — theme, preferred model, import/export, and reset.

Everything is saved in this browser's local storage only.
