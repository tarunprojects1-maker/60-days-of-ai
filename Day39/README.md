# Day 39 – PDF Splitter & Merger

## Objective

The objective of today's experiment was to understand how PDF processing applications work by building an interactive tool that can split large PDF files into smaller documents and merge multiple PDF files into a single document. The activity focused on file management, document processing, and creating a user-friendly interface for handling PDF operations.

---

## What I Did

In today's experiment, I generated the PDF Splitter & Merger application as an HTML project and tested it in my browser. After completing the initial setup, I explored both the PDF Splitter and PDF Merger features.

First, I uploaded a PDF file and tested the splitting functionality by dividing the document into smaller sections. I previewed the generated output and downloaded the processed PDF to verify that the splitting process worked correctly.

Next, I tested the PDF Merger by uploading multiple PDF files and combining them into a single document. After the merge operation was completed, I previewed the merged PDF and downloaded the final output to confirm that all pages were successfully combined in the correct order.

Finally, I captured screenshots of the important stages, including PDF upload, processing, preview, and downloaded results, and documented the overall learning from the experiment.
