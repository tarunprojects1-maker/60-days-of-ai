How this was researched

Methodology

Each criterion was scored from a single representative, sourced metric rather than a blended index, so every number on this page can be traced to one citation. Scores are normalized 0–100 per criterion (best observed value = 100), then combined using your weights to produce the ranking.

Pricing

We used a like-for-like ~2 vCPU / 8GB general-purpose instance (AWS t3.medium, GCP e2-medium, Azure B2s, DigitalOcean's closest Premium Droplet tier) as the comparison unit, since it's the smallest common denominator across all four catalogs and the figure most enterprise FinOps teams benchmark first. AWS and Azure landed close together (~$30/mo); GCP came in lower due to automatic sustained-use discounts; DigitalOcean was lowest and most predictable, with flat bandwidth overage pricing instead of the hyperscalers' variable egress fees.

Compliance & security

AWS publishes an explicit count (143 certifications) on its compliance page, which is unusually specific — most vendors just list frameworks rather than a total. GCP and Azure publish long but uncounted lists spanning SOC 1/2/3, ISO 27001/27017/27018/27701, FedRAMP, HIPAA, and PCI DSS; we counted the named frameworks visible in each vendor's own compliance documentation as a proxy. DigitalOcean's list is real but visibly shorter — SOC 2 Type II, SOC 3 Type II, PCI-DSS SAQ-A, HIPAA-eligible (as of July 2024), GDPR, and CSA STAR Level 1 — which is consistent with its positioning toward startups rather than regulated enterprise.

Service breadth

Flagged as estimate. None of the four vendors publish an official, consistently-defined "total services" count, and third-party counts vary by how granular a "service" is defined (e.g. is each AWS Lambda runtime a separate service?). The figures shown are informed approximations based on each vendor's public service-catalog navigation as of mid-2026, not audited totals. Treat differences of a few dozen as noise; treat the order-of-magnitude gap between the hyperscalers and DigitalOcean as the reliable signal.

SLA uptime

We used each vendor's flagship compute SLA at its strongest standard (non-negotiated) configuration: AWS EC2 Region-Level SLA (99.99%, multi-AZ), GCP Compute Engine multi-zone SLA (99.99%), Azure VM SLA for two-or-more instances across Availability Zones (99.99%), and DigitalOcean's per-Droplet Monthly Uptime commitment (99.99%). Note these SLAs are not directly comparable in structure — AWS/GCP/Azure figures require multi-zone deployment to hit 99.99%, while DigitalOcean's 99.99% is an instance-level commitment for a single Droplet — a genuine architectural difference we could not collapse into one number, so we note it here rather than in the score.

Conflicts we resolved

  • Some third-party blogs cite AWS EC2 single-instance SLA (99.5%) instead of the region-level, multi-AZ figure (99.99%). We used the multi-AZ figure because it matches how enterprise workloads are actually architected for production.
  • DigitalOcean marketing materials advertise "99.99% uptime SLA" broadly; the actual published Droplet SLA document specifies this is an instance-level commitment, structurally different from the hyperscalers' region-level guarantees. We used the vendor's own SLA document as the source of record.
  • Pricing figures from different aggregators varied by a few dollars depending on region and month queried; we used the most recent (2026) figures and note the source.
