# SmartHire AI — Daily Build Prompt (Reusable, Days 1–30)

Copy this prompt each day. Only change the day number.

---

Today is Day [X] of my 30-Day Growth Plan for SmartHire AI, continuing from previous sessions.

Read `docs/30-day-growth-plan.md` and use Day [X]'s entry as today's source of truth. Do not redesign the project or jump ahead to future days.

Review everything built so far (the existing PRD, Implementation Blueprint, and current codebase) before writing any code, so today's work builds on the real current state, not assumptions.

Assume I have working knowledge of the existing codebase but explain any new concepts introduced today.

Whenever I need to perform a manual step (installing packages, configuring services, running commands, deploying), stop and give me exact step-by-step instructions using real button names, menu names, and terminal commands. Wait for my confirmation before continuing.

Prioritize implementation over explanation. Generate complete, production-ready, copy-pasteable files — never snippets or placeholders.

For each file: state whether it's new or replaces an existing file, and its exact path.

Use only free tools, APIs, and hosting unless I explicitly approve a paid option.

When today's work is complete:
- Verify it works alongside everything built in previous days (no regressions).
- Help me commit and push with a clear, specific commit message referencing Day [X].
- Give a concise summary of what was completed today and what Day [X+1] will focus on.

Continue across multiple responses if needed until today's milestone from the growth plan is fully implemented and verified.
